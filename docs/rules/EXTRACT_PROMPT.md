# 書轉規則：固定抽取提示詞

每一本新書都用同一段提示詞跑一次，輸出存成 `docs/rules/<書名代號>.json`。
固定格式的用意是：不同書抽出來的東西可以直接比對與合併，不會每本書一個樣。

## 使用方式

1. 書的清洗後全文在 `/Volumes/4T/EK_Knowledge_Library/書籍重整/行銷寫作/<資料夾>/legacy_cleaned.md`
2. 先用標題列出章節，挑出跟標題、開場、小標、結構有關的章，只餵那幾章，不要整本丟
3. 用下面這段提示詞跑
4. 輸出存成 `docs/rules/<書名代號>.json`
5. 依 `MERGE.md` 的規範決定每一條是新增、強化還是衝突
6. 併進 `src/data/skills/` 底下對應的規則檔，每條都要帶出處
7. 更新 `coverage.md`

## 提示詞

```
你在幫一個繁體中文的文章生成系統抽取可執行的寫作規則。

從下面這段書的內容裡，抽出所有關於「標題、開場段、段落小標、文章結構」的規則。

每一條輸出這些欄位：
- rule：規則本身，一句話，寫成可以直接放進提示詞的祈使句
- when：什麼情況適用
- example：書中的原始範例，原文照抄，沒有就留空字串
- chapter：章節或節名
- tested：書裡有沒有附實際測試數據（分版測試、回應率等），true 或 false
- scope：這條屬於 title、opening、subhead 還是 structure

規則：
1. 只抽能寫進檢查表的東西。心法、作者生平、產業八卦不要抽。
2. 原文沒有的不要補，不要自己延伸或改良。
3. 只適用於商品廣告的規則（報價、產品規格、競品替換、折扣）要標 scope 為 ad_only。
4. 全部用繁體中文，純文字，不用 Markdown 符號，不用破折號。
5. 範例保留原文語言，不要翻譯。

只回傳 JSON：{"book":"","author":"","rules":[{"rule":"","when":"","example":"","chapter":"","tested":false,"scope":""}]}
```
